# Easy Cheats Menu — меню читов для The Sims 4

Скриптовый мод для версии игры **1.127.41.1030**. Даёт меню читов, которое открывается одной командой
и работает кликами мыши. `testingcheats` включать не нужно: все вызовы сверены с декомпилированным кодом игры
и идут напрямую, без встроенных читов.

## Установка
1. Скопируйте **оба** файла `dist/EasyCheats.ts4script` и `dist/EasyCheats.package` в
   `Документы\Electronic Arts\The Sims 4\Mods\` (прямо в `Mods` или в одну подпапку, не глубже).
2. В игре: *Настройки → Другое* → включите «Пользовательский контент и моды» и «Моды сценариев разрешены».
3. Перезапустите игру.

После загрузки участка появится уведомление «Мод загружен».

## Как пользоваться
Кликните по любому симу (и по своему тоже) → **Easy Cheats**. Меню откроется для этого сима.
Или: Ctrl+Shift+C → `uic` → Enter (для активного сима).

| Раздел | Что можно сделать |
|---|---|
| Деньги | +§1 000 / +§50 000 / +§1 000 000, −§1 000, ввести точную сумму, обнулить |
| Потребности | заполнить все (персонажу или всей семье), выставить каждую от −100 до 100 |
| Навыки | уровень 1–10 любого навыка, добавить новый навык, всё на максимум |
| Мудлеты | удалить любой мудлет или все негативные сразу |
| Отношения | дружба (и романтика — только у взрослых и не родственников) от −100 до 100 |
| Семья | назначить/убрать родителя или ребёнка, сделать братом/сестрой, поженить, развести |
| Карьера | повысить, понизить, продуктивность на максимум |
| Жизненные цели | завершить текущий этап, очки удовлетворения |
| Сезоны | сменить сезон (нужно «Времена года») |
| CAS | открыть персонажа в полном редакторе |

Быстрые команды: `uic.money 5000`, `uic.setmoney 100000`, `uic.needs`, `uic.needs_household`,
`uic.maxskills`, `uic.cleanbuffs`, `uic.help`.

## Семья — как это устроено
В игре родство хранится в семейном древе (у каждого сима записаны мать и отец), а значки «Отец»,
«Сестра», «Кузен» игра выводит из древа. Мод меняет только древо — теми же функциями, что игра
использует при рождении ребёнка, — и сразу пересчитывает значки у всех затронутых родственников.
* Братья/сёстры = общие родители (как в игре). Если у сима нет родителей, сначала назначьте их.
* Защита: нельзя стать родителем себе, своему предку (петля), быть младше ребёнка, родителем
  может быть только взрослый; вступать в брак — только взрослые и не родственники.
* Каждое изменение спрашивает подтверждение. **Перед изменением родства сохраняйте игру под новым именем.**

## Сборка из исходников
Игра загружает только байткод **Python 3.7**:
```
py -3.7 build.py
```
Результат: `dist/EasyCheats.ts4script`.

Файл `dist/EasyCheats.package` (пункт меню сима и его название на всех языках):
```
cd tools/package && npm install && node build-package.js
```

## Ограничения
* Клики прямо по счётчику денег, полоскам потребностей и т. п. (как в UI Cheats Extension) требуют
  правки Flash-интерфейса самой игры (файлы GFx из её .package). Этот мод их не трогает.
  Поэтому он открывается через своё меню, зато не ломается от каждого патча интерфейса.
* В версии 1.127 могла измениться внутренняя работа семейного древа. Мод поддерживает и старый,
  и новый вариант (как библиотека Sims4CommunityLibrary), но это самое непроверенное место.
* Мод не проверялся в запущенной игре. Если какой-то пункт выдаст «Ошибка: …», пришлите текст ошибки.
